# Multi-Agent Orkestrator

Bu skill, projeyi farkli ajanlara boler ve paralel calistirir.

## Agent Secim Matrisi

### Hizli Agent (Hafif Isler)
- Basit UI tasarimlari, CSS duzenlemeleri
- Kucuk HTML/React component'ler
- Renk semasi degisiklikleri

### Dengeli Agent (Orta Isler)
- Tasarim + basit mantik
- Interactive UI, form validation
- State management, API entegrasyonu

### Guclu Agent (Kompleks Isler)
- Backend logic, database semasi
- API endpoints, authentication
- Complex algorithms, security

## Gorev Dagilimi Workflow
1. Proje Analizi - Gorevleri kategorize et
2. Paralel Gorev Olusturma - Her ajana uygun is ver
3. Es Zamanli Calistirma - Tum ajanlar paralel calisir
4. Sonuc Entegrasyonu - Parcalari birlestir

## Koordinasyon
- Dependencies yonetimi: Backend > Frontend Logic > UI Design
- Conflict resolution: Backend oncelikli
- Hiz kazanci: Paralel calisma ile 2x hizli
