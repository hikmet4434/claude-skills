# MCP Akilli Secici

Bu skill, kullanici istegine en uygun MCP'yi otomatik secer.

## MCP Secim Matrisi

| Istek Turu | MCP | Tetikleyiciler |
|------------|-----|----------------|
| Tasarim & Gorsel | Canva | tasarim yap, logo, poster, infographic |
| Deployment | Vercel | deploy et, yayinla, online yap |
| AI Modelleri | Hugging Face | AI modeli, goruntu olustur, text-to-image |
| Web Arama | Web Search | internette ara, guncel bilgi |
| Dosyalar | Google Drive | dosyamda ara, drive'da bul |
| Tarayici | Chrome/Brave | tarayiciyi ac, URL'ye git |
| Turk Hukuk | Yargi MCP | mahkeme karari, yargitay, emsal karar |
| Turk Mevzuat | Mevzuat MCP | kanun, yonetmelik, teblig |

## Karar Agaci
1. Istek Analizi - En uygun MCP'yi belirle
2. MCP Sec - Otomatik devreye sok
3. Execute - Kullaniciya sormadan calistir

## Coklu MCP Senaryolari
- Tasarim + Deployment: Canva ile tasarla, Vercel ile deploy et
- Web Arama + Drive: Web'den veri topla, Drive'daki raporu guncelle
- Hukuk + Mevzuat: Mevzuat ara, ilgili kararlari bul
