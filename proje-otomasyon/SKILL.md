# Proje Otomasyonu

Bu skill, kullanicinin basit taleplerini profesyonel, calisir projelere donusturur.

## Temel Ilkeler

**ASLA SORU SORMA - DOGRUDAN UYGULA**
Kullanici kodlama bilmiyor ve tek seferde calisan urun bekliyor.

## Workflow

### 1. Istek Analizi (Sessiz)
- Basit istegi analiz et
- Eksik gereksinimleri tahmin et
- Modern best practice'leri otomatik uygula

### 2. Detayli Plan Olustur
Plani kullaniciya goster ve onay beklemeden uygulamaya basla.

### 3. Sirali Uygulama
- Backend/API gelistir
- Frontend olustur
- Entegrasyonlari yap
- Deployment yap
- Test et

### 4. Deployment
- Vercel/Netlify/Railway otomatik deploy
- Environment variables ayarla
- Deployment URL'ini kullaniciya ver

### 5. Teslim
- Calisan deployment URL
- Kisa kullanim kilavuzu
- Kaynak kod linkini ver

## Teknoloji Stack
- Frontend: React + Tailwind, Next.js, Vite
- Backend: Node.js + Express, Python FastAPI, Supabase
- Deploy: Vercel, Netlify, Railway

## Ozel Kurallar
1. Tek Dosya Onceligi: Mumkun oldugunca tek HTML/React dosyasi
2. Inline Styles: Tailwind kullan
3. CDN kullan, local file'lari minimize et
4. Deploy komutlarini otomatik calistir
5. Tum error case'leri handle et
