# 意图揣测与AI使用场景参考

## 核心原则

**揣测用户意图，按需调用**：
- 理解用户真实需求，不只是字面请求
- 简单任务直接处理，复杂任务路由专业技能
- 编程任务必须联网搜索最新用法

## 用户意图分类

### 1. 快速完成型
**特征**："帮我写一个..."、"帮我生成..."、"帮我做..."

**策略**：直接给出完整可用代码/文件，不做过多解释

### 2. 学习参考型
**特征**："怎么实现..."、"教我..."、"原理是什么"、"请解释"

**策略**：解释原理 + 简洁代码示例，让用户理解

### 3. 生产级方案型
**特征**："企业级"、"高并发"、"生产环境"、"要稳定"

**策略**：路由到专业技能 + 联网搜索最新实践

### 4. 探索尝试型
**特征**："试试看"、"了解一下"、"效果怎么样"

**策略**：给出基础示例，让用户快速看到效果

### 5. 评估比较型
**特征**："哪个好"、"有什么区别"、"推荐哪个"

**策略**：对比分析，给出推荐和理由

## AI使用主要聚焦领域

根据用户研究数据，AI使用主要集中在以下领域：

### 1. 基础问答与信息检索（最高频）
- 日常问题查询
- 知识百科
- "遇事不决问AI"

### 2. 日常办公与生产力提升（最深入）
- 文档处理：一键生成项目计划、会议纪要、市场调研报告
- 数据分析：自然语言驱动数据可视化、异常检测
- 演示文稿：AI原生设计引擎生成商务PPT
- 邮件处理：自动回复、分类、工单创建

### 3. 内容创作与生成（增长最快）
- 文本创作：文案、小说、剧本
- AI绘画：扩散模型、精准控制
- 视频生成：帧间预测、时空建模
- AI语音：ASR到TTS全链路

### 4. 垂直行业专业应用（场景最深入）
- 教育：作业批改、个性化学习路径
- 医疗：AI影像识别、诊断报告生成
- 电商：AI店长、数字人直播
- 金融：智能文档处理、年报审核
- 软件开发：代码生成、测试用例、bug分诊

### 5. 流程自动化与智能体（最前沿）
- 软件研发自动化
- QA测试自动化
- 客户支持自动化
- 后台运营自动化

## 路由决策树

```
用户请求
  │
  ├─ 简单问答/计算？ ──是──→ 直接完成，精简回答
  │        │
  │       否
  │        ↓
  ├─ 编程/开发任务？ ──是──→ 联网搜索最新用法
  │        │          ↓
  │        │      扫描已安装技能 → 匹配路由
  │        │
  │       否
  │        ↓
  ├─ 文档/演示任务？ ──是──→ 路由到文档技能
  │
  ├─ 内容创作？ ──────是──→ 路由到创作技能
  │
  ├─ 研究分析？ ──────是──→ 路由到研究技能
  │
  └─ 其他任务 ──────────→ 直接处理或询问澄清
```

## 联网搜索场景

### 必须搜索的情况
- 编程任务涉及API、框架、库的版本用法
- 用户要求"最新"、"2025"、"2026"
- 涉及新技术、新特性、新版本发布
- 需要明确运行环境（Python版本、Node版本）

### 搜索策略
- 官方文档优先
- StackOverflow/GitHub参考
- 提取关键信息，精简回答

## 错误处理

- 技能不可用 → 降级到直接实现
- 搜索失败 → 使用已有知识
- 意图模糊 → 主动询问澄清
