# 技能扫描与自动路由

## 技能评分

每个候选技能 0-7 分：

- 用户明确指定：+3
- 文件类型匹配：+2
- 任务动词匹配：+1
- 技术栈/平台匹配：+1

最高分自动调用。若并列，选更具体的技能。

## 读取策略

1. 扫描目录中的 `*/SKILL.md`。
2. 只读取 frontmatter。
3. 选出候选技能。
4. 读取候选技能完整说明。
5. 调用或按其说明执行。

## 降级策略

- 没有技能目录：直接完成任务，并提示可设置 `USE_WISELY_SKILL_DIRS`。
- 目录不可读：说明权限问题。
- 技能调用失败：说明失败点，直接处理或给手动命令。
- 技能冲突：选更具体的那个。

## 文件格式优先级

- `.pptx` → slides/PPT 技能
- `.docx/.doc` → document/DOCX 技能
- `.xlsx/.csv` → spreadsheet/data 技能
- `.pdf` → PDF 技能
- 图片 → vision/image 技能
- 代码仓库 → coding/framework 技能
